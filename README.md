# 文件压缩器

发邮件附件太大发不出去，微信传图片被压缩得面目全非，上传简历提示文件过大。

这些问题的根源都一样：图片文件太大了。

之前要么用在线压缩网站（要注册、限制次数、上传到别人服务器），要么用 PS 一张张手动调（太慢）。

所以做了这个批量图片压缩工具。

## 功能

**批量压缩**：一次拖进去几十张图片，一键全部压缩。不用一张一张处理。

**质量可调**：压缩质量从 10% 到 100% 自由调节，平衡文件大小和画质。

**尺寸缩放**：可以设置最大宽高，自动等比缩放。适合限制图片尺寸的场景。

**实时预览**：压缩前后的文件大小、压缩比例一目了然。

**一键保存**：压缩完直接保存到桌面 compressed 文件夹，自动打开目录。

## 支持格式

- JPG / JPEG
- PNG
- WebP

## 优势

**本地处理**：图片不会上传到任何服务器，全部在自己电脑上压缩。隐私安全。

**零限制**：没有"每天免费5张"的限制，想压多少压多少。

**批量处理**：一次处理几十上百张，不用手动一张张来。

**高压缩率**：使用 mozjpeg 算法，同等画质下文件更小。

**零依赖**：安装包直接用，不需要装任何东西。

## 安装

从 Releases 下载安装包，双击安装即可。

源码运行：

```bash
npm install
npm start
```

## 技术栈

- Electron 桌面框架
- sharp（高性能图片处理库）
- Express 本地 API
